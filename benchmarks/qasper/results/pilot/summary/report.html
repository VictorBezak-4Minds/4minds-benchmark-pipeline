Method

How the benchmark ran

Protocol

  • Dataset: QASPER v0.3 test release (416 papers, 1451 questions). Pilot: 25 questions, 1 per paper, stratified by answer type, seed 42.
  • Corpus: the 25 question papers plus 39 other test papers (64 papers, 1,567,657 characters), in one text file.
  • Every system got the same corpus and the same system prompt.
  • Each query names its paper: In the paper "<title>": <question>.
  • Scoring: the official qasper_evaluator.py, unchanged, on a gold file with only the pilot questions.
  • No system answered a question before its ingestion was complete (a readiness check gates each run).

Systems

  • Gemini + File Search: Gemini 3.8 Flash with Gemini File Search (Interactions API), top-k 5; the model decides how many searches to make.
  • LightRAG + Gemini: LightRAG 1.2.5 with Gemini 3.8 Flash, hybrid mode, top-k 5, bge-large-en-v1.5 embeddings.
  • 4Minds (SYMI): 4Minds prod, SYMI engine (REST/SSE), model GPT-OSS-120B, same dataset and persona.
  • 4Minds (Constellations): 4Minds prod, Constellations engine (WebSocket), model GPT-OSS-120B, chunk-level graph.
Read before you share

Notes and caveats

  • Pilot: 25 questions. The confidence intervals are wide and overlap; do not rank systems from this table.
  • Deviation from the paper's setting: all corpus papers are in one knowledge base, and each query names its paper (In the paper "<title>": <question>). The paper's model receives the question plus that one paper.
  • The corpus is a slice: the 25 question papers plus 39 other test papers (64 of 416).
  • Tables and figures are available only as captions (no images).
  • The papers are from before 2021 and are probably in the training data of the models.
  • Answer F1 is token overlap with the best-matching reference, so long answers get low scores even when they are correct. Compare the answer length column.
  • By-type scores use the type of the best-matching reference (official rule); some questions have references of more than one type.
  • Only Answer F1 is reported. Evidence F1 is not used (predicted_evidence is empty).
